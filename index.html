Cipher Mode Mathematical Formulations

Electronic Codebook (ECB) Mode

NIST Prohibited for Confidentiality
Encryption: Ci = EK(Pi)
Decryption: Pi = DK(Ci)

Structural Vulnerability: In ECB mode, every 16-byte block of plaintext Pi maps deterministically to the identical ciphertext block Ci under key K. When encrypting structured raster images, contiguous regions of identical pixels (such as solid backgrounds or uniform color patches) produce repeating ciphertext blocks, completely preserving object outlines and geometric silhouettes.

Galois/Counter Mode (GCM)

NIST Recommended Authenticated Mode
Keystream: Si = EK(IV ∥ i)
Encryption: Ci = Pi ⊕ Si
Auth Tag: T = GHASHH(A, C, L) ⊕ EK(IV ∥ 0)

Authenticated Diffusion: GCM transforms AES into a stream cipher via a counter combined with a unique 96-bit Initialization Vector (IV). Because the block counter i increments with each block, identical plaintext blocks are XORed with distinct keystream bytes, delivering maximum Shannon entropy (~8.0 bits/byte) and full visual obscurity.
