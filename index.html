💡 Why does AES-ECB leak image structure? (The Cryptographic Math) ▼

Electronic Codebook (ECB) Mode

In ECB mode, each 16-byte block of plaintext \(P_i\) is encrypted independently using the key \(K\): $$\text{Ciphertext } C_i = E_K(P_i)$$

If two plaintext blocks are identical (\(P_a = P_b\)), their ciphertexts are guaranteed to be identical (\(C_a = C_b\)). Because images contain vast contiguous regions of identical pixel colors (e.g. flat background areas), those areas turn into repeating ciphertext tiles, preserving the visual shape/silhouette of logos and objects.

Galois/Counter Mode (GCM)

In GCM mode, AES operates as a counter-mode cipher combined with a Galois authentication tag: $$\text{Ciphertext } C_i = P_i \oplus E_K(\text{IV} \parallel i)$$

Because the block counter \(i\) increments for every single 16-byte block, every block uses a unique keystream byte sequence. Even if \(P_a = P_b\), \(C_a \neq C_b\). The image is transformed into pure statistical static, completely hiding all visual patterns.
